
# MOA (모아)

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개: 교내·교외 활동과 봉사활동을 모아 기록하고, 나의 성장을 확인하는 포트폴리오 관리 앱입니다.
- 누구를 위한 앱인가: 다양한 활동 경험을 한곳에 정리하고 싶은 학생을 위한 앱입니다.
- 어떤 상황에서 쓰는가: 활동 후 경험과 배운 점을 기록하거나, 자기소개서·면접에 활용할 경험을 정리할 때 사용합니다.

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 회원가입과 로그인 | 회원가입·로그인·로그아웃 화면 | Supabase Auth를 이용한 계정 인증과 회원 정보 연결 |
| 2. 활동 포트폴리오 관리 | 교내·교외·봉사활동 등록, 목록 조회, 수정·삭제 화면 | Server Action과 Prisma를 이용한 활동 저장·조회·수정·삭제 및 소유자 확인 |
| 3. 활동 현황 확인 | 활동별 건수, 누적 봉사 시간, 활동 달력을 보여주는 대시보드 | 로그인한 회원의 활동 통계 집계와 연도별 달력 데이터 조회 |

더 만든 기능:
- 이메일을 통한 비밀번호 재설정
- 활동 기간과 진행 중 여부 기록
- 활동 내용과 배운 점, 유형별 역할·성과 또는 봉사 시간·장소 기록
- 활동 목록 페이지 나누기
- 입력 오류 안내와 삭제 확인

## 기술 스택
- 프론트엔드: Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, React Hook Form, Zod
- 백엔드: Next.js Server Actions·Route Handler, Supabase Auth, Prisma 7
- 데이터(어디에, 무엇을): Supabase PostgreSQL에 회원 프로필과 활동 기록을 저장합니다. 비밀번호와 로그인 세션은 Supabase Auth에서 관리합니다.

## 실행 방법
1. Node.js 24와 npm을 준비한 뒤 프로젝트 폴더에서 `npm ci`를 실행합니다.
2. [DB 설정 안내](docs/SUPABASE_SETUP.md)와 [인증 설정 안내](docs/AUTHENTICATION.md)에 따라 환경 변수, 인증서, Supabase Auth와 DB 테이블을 준비합니다. 로그인과 활동 저장에는 해당 설정이 필요합니다.
3. `npm run dev`를 실행하고 브라우저에서 http://localhost:3000 에 접속합니다. 다른 주소가 터미널에 표시되면 해당 주소를 사용합니다.

배포 주소(있으면): 확인 필요
