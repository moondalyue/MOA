프로젝트를 시작하기 전에 [SETUP.md](docs/SETUP.md)를 먼저 읽으세요.
프로젝트 개요
- 한 줄 소개: 교내·교외 활동과 봉사활동을 모아 나의 성장 과정을 기록하는 포트폴리오 웹앱입니다.
- 누구를 위한 앱인가: 다양한 활동 경험을 한곳에 정리하고 싶은 학생을 위한 앱입니다.
- 어떤 상황에서 쓰는가: 활동을 마친 뒤 경험과 배운 점을 기록하거나, 자기소개서·면접을 준비하면서 지난 활동을 돌아볼 때 사용합니다.
주요 기능
과제의 꼭 있어야 하는 기능	화면(프론트엔드)	API(백엔드)
1. 회원가입과 로그인	회원가입·로그인·로그아웃, 비밀번호 재설정 화면	Supabase Auth를 통한 인증과 세션 관리, 회원 전용 화면 접근 확인
2. 활동 포트폴리오 관리	교내·교외·봉사활동 등록, 목록 조회, 수정·삭제 화면	Server Action과 Prisma를 통한 활동 저장·수정·삭제, 입력 검증 및 본인 기록 접근 확인
3. 활동 대시보드와 달력	전체·유형별 활동 수, 누적 봉사 시간, 활동 달력	로그인한 회원의 활동 집계와 연도별 달력 데이터 조회


더 만든 기능:
- 활동 내용뿐 아니라 담당 역할, 성과, 배운 점까지 기록할 수 있습니다.
- 봉사활동의 시간과 장소를 별도로 관리합니다.
- 달력에서 날짜나 활동을 선택해 해당 기록을 확인할 수 있습니다.
- 활동 목록을 나누어 불러오는 페이지 이동 기능을 제공합니다.
- 공개·비공개 선택을 저장합니다. 공개 공유 화면과 공유 URL은 아직 제공하지 않습니다.
기술 스택
- 프론트엔드: Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, FullCalendar, React Hook Form
- 백엔드: Next.js Server Actions·Route Handler, Supabase Auth, Prisma 7, Zod
- 데이터(어디에, 무엇을):
  - Supabase PostgreSQL에 회원 정보와 활동 기록을 저장합니다.
  - 활동 기록에는 유형, 제목, 기관, 기간, 역할, 봉사 시간, 장소, 활동 내용, 성과, 배운 점, 공개 여부가 포함됩니다.
  - 비밀번호와 로그인 세션은 Supabase Auth에서 관리합니다.
실행 방법
1. Node.js 24와 npm을 준비하고, 프로젝트 폴더에서 npm ci를 실행합니다.
2. .env.example을 참고해 프로젝트 루트에 .env를 준비합니다. [DB 설정 안내](docs/SUPABASE_SETUP.md)와 [인증 설정 안내](docs/AUTHENTICATION.md)에 따라 Supabase 연결 정보, 인증 설정, 앱 주소와 DB 테이블을 준비합니다. 실제 비밀값은 Git에 올리지 않습니다.
3. npm run dev를 실행한 뒤 브라우저에서 http://localhost:3000에 접속합니다. 터미널에 다른 주소가 표시되면 해당 주소를 사용합니다.
배포 주소(있으면): 확인 후 기입
AI 활용 내역
- 사용한 도구: OpenAI Codex
- 주요 프롬프트(그대로 붙여 넣기): 실제 개발에 사용한 프롬프트를 대화 기록에서 복사해 추가해야 합니다.
- AI가 만든 것 / 사람이 고친 것: AI를 활용해 인증, 활동 관리, 대시보드·달력 구현과 검증을 진행했습니다. 사람이 직접 수정한 부분과 세부 작업 구분은 실제 작업 내역에 맞춰 추가해야 합니다.
- 결과를 확인한 방법:
  - 기존 작업 기록에서 타입 검사, 린트, DB 스키마 검사, 빌드와 자동 테스트 결과를 확인했습니다.
  - DB의 활동 등록·조회·수정·삭제와 비회원 접근 제한을 확인한 기록이 있습니다.
  - 실제 회원가입·로그인, 비밀번호 재설정 메일, 모바일 화면과 브라우저 사용성은 추가 확인이 필요합니다.
