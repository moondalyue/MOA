# MOA 로컬 버전

대학 생활의 활동과 경험을 STAR로 모으는 개인용 첫 버전입니다.

## 실행

Node.js 24와 이 저장소의 개발 패키지가 필요합니다. 최초 `npm ci`, 이후 `npm run dev`를 실행하고 http://localhost:3000 을 여세요. 이 PC에서는 루트의 `MOA-실행.cmd`를 더블클릭해 실행할 수도 있습니다. 창을 닫으면 서버가 종료됩니다. 기본 포트가 사용 중이면 터미널에 표시된 주소를 확인하세요.

## 메뉴와 바로가기

주 메뉴는 모아보드·내 기록·달력·자기소개서입니다. 모아보드의 활동·경험·즐겨찾기·다가오는 마감 카드를 누르면 해당 화면으로 이동합니다. 즐겨찾기는 경험 목록에서 즐겨찾기 필터가 켜진 상태로 열립니다. 활동 분야 분류와 저장된 기록은 유지됩니다.

## 사용 순서

1. **내 기록 → 활동 → 활동 추가**에서 활동명·분야·기관·기간·시간·역할을 기록합니다.
2. 해당 활동에서 **경험 기록**을 눌러 STAR 에피소드를 추가합니다. 한 활동에 여러 경험을 연결할 수 있습니다.
3. 회고와 역량·감정 키워드, 즐겨찾기, 사진·PDF 증빙을 추가합니다. STAR는 미완성이어도 저장할 수 있습니다.
4. **내 기록 → 경험**에서 검색하거나 역량·분야·즐겨찾기로 좁혀봅니다. 경험 카드를 누르면 내용을 보고 수정할 수 있습니다.
5. **달력**에 활동 기간과 관심 공모전·대외활동의 마감일을 모읍니다. 날짜를 눌러 그날의 활동을 확인하세요. 등록된 관심 일정을 누르면 수정할 수 있습니다.
6. **자기소개서**에서 지원 분야와 문항을 입력하고 활용할 경험을 선택합니다. 구성 자료를 복사하거나, 전송에 동의한 뒤 역량 분석·초안 작성·문장 첨삭을 요청합니다.

## VS Code 실행

이 프로젝트 폴더를 VS Code에서 열고 **실행 및 디버그 → MOA 웹앱 실행 및 디버깅 → F5**를 누르세요. 개발 서버가 준비되면 브라우저가 열립니다. Windows 설정은 이 PC의 Codex 제공 Node.js를 사용합니다. 다른 PC에서는 Node.js 24를 설치하고 `.vscode/launch.json`의 `windows.runtimeExecutable`을 설치 경로로 바꾸거나 `windows` 항목을 제거하세요.

## AI 연결

프로젝트 루트의 `.env.local`에 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 설정한 뒤 서버를 재시작하세요. API 키는 본인 계정에서 발급하고 모델은 해당 계정에서 사용할 수 있는 Responses API 지원 모델 이름을 입력합니다. 키를 채팅이나 소스 코드에 붙여 넣지 마세요. 실제 호출에는 OpenAI API 요금이 발생합니다.

선택한 경험의 텍스트·지원 분야·문항·첨삭 입력만 전송하며 사진과 PDF는 전송하지 않습니다. API 요청은 `store: false`를 사용하지만 제공 업체의 데이터 처리 정책과는 별개입니다. 결과는 사실 검토 후 사용하세요. 요청은 한 번에 하나, 최소 10초 간격이며 응답 대기는 60초입니다. 오류가 나도 기존 기록과 이전 AI 결과는 유지됩니다.

회원 인증을 아직 연결하지 않았으므로 AI 호출은 localhost 개발 환경에서만 허용합니다. 운영 배포에서는 호출이 차단되며 회원 인증과 사용자별 사용량 제한을 추가한 뒤 공개해야 합니다. 기록·달력 기능은 AI 설정 없이 사용할 수 있습니다.

## 저장과 증빙

- 실제 DB와 로그인은 연결하지 않았습니다. IndexedDB에 이 기기·브라우저·사이트 주소별로 저장됩니다.
- 브라우저 데이터 삭제, 시크릿 창 종료, 주소·포트 변경 시 기록이 사라지거나 보이지 않을 수 있습니다. 여러 기기 사이에는 동기화되지 않습니다.
- 사진은 JPG·PNG, 문서는 PDF를 지원하고 파일당 최대 10MB입니다. 파일 헤더를 확인하며 서버에 업로드하지 않습니다. 이는 바이러스 검사와 동일하지 않습니다.
- 증빙은 해당 경험을 열어 사진 미리보기·다운로드·첨부 해제를 할 수 있습니다. 첨부 해제는 저장 버튼을 누를 때 반영됩니다.
- **저장 및 백업**에서 기록과 증빙을 함께 JSON으로 내보내고 가져올 수 있습니다. 가져올 수 있는 백업은 100MB 이하입니다. 큰 첨부 모음은 먼저 개별 다운로드 후 정리하세요.
- 가져오기는 기존 기록에 새 식별자로 추가합니다. 같은 백업을 여러 번 가져오면 중복됩니다. 기존 기록을 덮어쓰거나 지우지 않습니다.
- 백업에는 개인 기록과 첨부 원본이 포함됩니다. 본인이 관리하는 위치에 보관하세요.
- 동시에 여러 탭에서 편집하지 마세요. 탭으로 돌아오면 저장된 기록을 다시 불러오지만 동시 편집 충돌 병합은 지원하지 않습니다.

## 현재 범위

- 마감일의 D-Day는 한국 날짜 기준입니다. 활동 달력에서 브라우저 알림을 켜면 앱이 열려 있는 동안 마감 7일·3일·1일 전과 당일에 하루 한 번 알려줍니다. 브라우저 권한과 운영체제 알림 설정이 필요합니다. 닫힌 상태의 메일·푸시 알림은 연결되지 않았습니다.
- AI 역량 분석·초안·첨삭은 서버 API 키와 모델을 설정한 로컬 개발 환경에서 사용할 수 있습니다. 설정 전에는 필요한 설정을 안내합니다.
- 지원 분야·문항은 영구 저장되지 않습니다. 필요한 결과는 복사하세요.
- 회원 로그인, 회원별 서버 DB, 기기 간 동기화는 다음 단계입니다.
- GitHub로 커밋·푸시하거나 웹에 배포하지 않았습니다.

## 검사

프로젝트의 `npm run check`, `npm run build`로 타입·린트·서식·빌드를 확인합니다. Prisma Client와 Next.js 타입 등 자동 생성물이 만들어지지만 실제 DB를 변경하는 명령은 아닙니다. 기존 Prisma 스키마와 환경 변수 설정을 유지합니다.
